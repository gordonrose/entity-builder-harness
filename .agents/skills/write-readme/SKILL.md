# Write a README

Read the repository-owned [canonical procedure](../../../.agentic/shared/skills/write-readme.md)
completely, then read its required standard and applicable template before
authoring. Follow those files as the source of truth. This entry point supplies
Codex discovery metadata only; it does not duplicate the writing rules or grant
additional write, installation, Git or deployment permissions.
