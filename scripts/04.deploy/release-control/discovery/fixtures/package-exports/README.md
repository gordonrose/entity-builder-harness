These `.txt` files preserve the three historical handwritten generator sources as
inert parser inputs. Tests never execute them. They verify that the old structural
artifact contract keeps its documented grammar and rejects modified helper text.

Current runtime generators derive their maps from actual compiler emissions and
fresh workspace manifests. The legacy syntax-only parser deliberately refuses
those generators: it cannot replace the compiler observation needed to establish
their output set. Actual Node execution, exact generated bytes, repeat calls,
selection, aliases and negative cases are covered by `test_workspace_runtime.py`,
`test_package_exports.py`, and the local runtime/build suites.
